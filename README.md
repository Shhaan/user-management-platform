# User CRUD Application

Django REST Framework + React + Redux

------------------------------------------------------------------------

## Overview

This is a full-stack User Management application implementing complete
CRUD (Create, Read, Update, Delete) functionality.

The backend is built using Django REST Framework, and the frontend is
built with React and Redux for structured state management.

The project demonstrates REST API development, frontend-backend
integration, and centralized state handling.

------------------------------------------------------------------------

## Features

-   Create new users
-   View list of users
-   Update user details
-   Delete users
-   RESTful API architecture
-   Redux-based global state management
-   API integration between frontend and backend
-   Clean and modular code structure

------------------------------------------------------------------------

## Architecture

### Backend

-   Django
-   Django REST Framework
-   ModelSerializer for validation
-   RESTful endpoints
-   JSON API responses

### Frontend

-   React
-   Redux
-   Axios / Fetch API integration
-   Component-based structure

------------------------------------------------------------------------

## API Endpoints (Example)

-   GET /users/ → Retrieve all users
-   POST /users/ → Create a new user
-   PUT /users/{id}/ → Update user
-   DELETE /users/{id}/ → Delete user

------------------------------------------------------------------------
